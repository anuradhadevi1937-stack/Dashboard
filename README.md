# VOYX Admin Pro - Sales & Operations Dashboard

A modern, high-performance sales analytics dashboard built with **React**, **TypeScript**, **Tailwind CSS**, and **Supabase**.

## 🚀 Features

- **Live Supabase Integration**: Real-time sales transactions, customer data, and sales representative tracking.
- **Dynamic KPI Tracking**: Gross Revenue, Total Orders, Average Order Value (AOV), and Active Customers with period-over-period comparisons.
- **Flexible Date Filtering**: Quick presets (Today, Yesterday, This Week, This Month, Previous Month) and custom date intervals.
- **Multi-Dimensional Filters**: Filter by sales representatives, SIM mode (eSIM vs. Plastic SIM), and customer search.
- **Visual Analytics**: Interactive daily revenue charts, monthly trajectory graphs, and top destination breakdowns.
- **Sales Rep Leaderboard**: Performance metrics, total deals closed, revenue generated, and wallet balances.
- **CSV Data Export**: Instant export of filtered order sets.

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS + Lucide Icons
- **Charts**: Recharts
- **Database**: Supabase (PostgreSQL)

## 📦 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/anuragsingh0412/voyx-admin-dashboard.git
cd voyx-admin-dashboard
```

### 2. Install dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Create a `.env.local` file in the project root:
```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 4. Start Development Server
```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
